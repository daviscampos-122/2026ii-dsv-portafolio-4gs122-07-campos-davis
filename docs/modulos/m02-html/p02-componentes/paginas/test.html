Página de prueba de rutas

Esta página auxiliar sirve para comprobar que las rutas relativas que suben un nivel (../) funcionan correctamente desde la subcarpeta paginas/.

Si el estilo, el ícono y la imagen cargan bien en el navegador, la ruta hacia la carpeta assets/ está bien escrita. Además, más adelante incrustaremos esta página dentro de la guía de componentes.
